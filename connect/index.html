Best clients

A raw telnet window works. It is also the least fun. These clients speak CP437, 16-color ANSI, and the little protocols that make a Mystic board look like a Mystic board:

  • SyncTERM — free, cross-platform, the usual recommendation.
  • NetRunner — from the Mystic author. Feels at home here.
  • mTelnet / MagiTerm / EtherTerm — other solid options if you already have a favorite.

From a regular terminal

Windows Terminal, macOS Terminal, or any Unix shell:

telnet boneyard-bbs.com 8073
ssh -p 8074 boneyard-bbs.com

Windows may need the Telnet Client optional feature, or you can skip that and install SyncTERM. SSH is the cleaner pipe if telnet is blocked on your network.

First call

  1. Connect. Wait for the login stack to paint.
  2. Apply for a new account. Pick a handle. Do not pick “Guest” as a personality.
  3. Read the new-user news. Then go look at the message menu before the file menu.

If a telnet:// link does nothing, your browser does not have a handler. That is normal. Use a client.
